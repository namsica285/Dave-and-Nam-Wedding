# Dave & Nam Wedding Website

Astro static site, English and Vietnamese (`/en/`, `/vi/`). Hosted on Vercel; domain daveandnam.com (Cloudflare DNS).

- `npm install`, then `npm run dev` or `npm run build`
- Design tokens: `src/styles/tokens.css`
- Copy and page titles: `src/i18n/ui.ts`
- Logo files: `public/brand/` (from Branding kit v9). Fonts are self-hosted in `public/fonts/`.
- The site is `noindex` and `robots.txt` blocks crawlers until launch.
